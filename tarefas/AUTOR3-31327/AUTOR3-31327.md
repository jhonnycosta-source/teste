CRITÉRIOS DE ACEITE

CENÁRIO 1 - Feature Toggle Desativada
Dado que a toggle AUTO_COTACAO_PREMIO_INFORMADO está desativada (default),
Quando o endpoint PUT /ofertas/{numeroCotacao}-{versaoCotacao}-{numeroOrcamento}/premios for acionado,
Então a API deve retornar HTTP 404 Not Found.

CENÁRIO 2 - Permissão do Usuário
Dado que a toggle AUTO_COTACAO_PREMIO_INFORMADO está ativa,
Quando a requisição for feita por um usuário que não possui o perfil de Analista Interno (validado via PerfilUtil),
Então a aplicação deve lançar a exceção BusinessUncheckedException.

CENÁRIO 3 - Validação de Prêmio Nulo ou Zero
Dado que os dados de entrada foram enviados no payload,
Quando o campo valorPremio for null ou igual a 0,
Então a aplicação deve lançar a exceção BusinessUncheckedException informando valor inválido.

CENÁRIO 4 - Busca de Orçamento Inexistente ou Status Inválido
Dado os parâmetros numeroCotacao, versaoCotacao e numeroOrcamento,
Quando o método buscarOrcamentoValido não encontrar o orçamento OU o orçamento possuir o status 4 ou 19 StatusOrcamentoEnum,
Então a API deve retornar HTTP 404 Not Found

CENÁRIO 5 - Motivo de Congelamento Divergente
Dado que o orçamento foi encontrado com sucesso,
Quando o motivo de congelamento (TipoMotivoCongelamentoEnum) for diferente de 4 (MOTIVO_FLEXIBILIZACAO),
Então a aplicação deve lançar a exceção BusinessUncheckedException.

CENÁRIO 6 - Prêmios atualizados com sucesso
Dado que o orçamento foi atualizado e salvo com sucesso,
Quando o endpoint responder,
Então deve retornar HTTP Status 200 OK contendo o orçamento atualizado, incluindo a nova flag de prêmio informado mapeada no contrato/schema
